# Charge2Login React — v6

Demo frontend interaktif: low battery → tarik konektor USB-C dari bawah → konektor masuk ke port → charging → login.

## Perubahan v6
- Kabel USB-C dibuat lebih tipis dan proporsional.
- Drag hanya bergerak vertikal, seperti menarik ritsleting.
- Jalur kabel pendek dan rileks dari bawah scene.
- Konektor berhenti pada posisi yang dihitung terhadap port USB-C HP.
- Saat terhubung, konektor masuk sebagian ke area port dan tubuh konektor berada di bawah frame HP sehingga tidak menembus layar.
- Port USB-C mendapat lip/slot dan glow halus ketika koneksi berhasil.
- Bagian lain dari UI dan alur tetap dipertahankan.
